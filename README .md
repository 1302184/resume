\## ✨ 核心亮点与特色



\* \*\*纯原生硬核技术栈\*\*：0 依赖，纯手写 HTML5 + CSS3 + 原生 JavaScript，不引入任何前端框架或沉重库，极致轻量。

\* \*\*独具匠心的杂志拼贴视觉\*\*：

&#x20; \* \*\*撕纸毛边效果\*\*：通过自定义 CSS 变量与多边形剪切（`clip-path: polygon(...)`）渲染逼真的纸张边缘与厚度投影。

&#x20; \* \*\*错落堆叠与网格\*\*：首页与实践舱运用动态/静态坐标偏移，打造错落有致的相片堆叠与“软木板”荣誉墙。

\* \*\*深思熟虑的移动端性能优化\*\*：

&#x20; \* \*\*背景重构\*\*：采用伪元素（`body::before`）完美解决移动端（如 iOS Safari）背景图固定滚动的解析 Bug。

&#x20; \* \*\*按需加载与懒加载\*\*：使用 `<picture>` 标签实现手机端头像缩略图按需加载，并全面启用原生 `loading="lazy"`，确保首屏秒开、滑动丝滑。

\* \*\*丰富的交互体验\*\*：

&#x20; \* \*\*全站图片灯箱（Lightbox）\*\*：支持点击任意图片放大查看大图、左右切换、索引计数及键盘快捷键操作。

&#x20; \* \*\*轻量留言板\*\*：利用原生 HTML 表单校验与 `mailto:` 协议实现优雅的客户端邮件调起，零后端也能实现互动。

\## 🛠️ 技术架构



\* \*\*结构 (HTML5)\*\*：语义化标签、无障碍属性、内嵌 iframe 网页预览。

\* \*\*样式 (CSS3)\*\*：CSS 变量系统、Flexbox 与 Grid 响应式布局、自定义多边形裁剪、硬件加速动画。

\* \*\*脚本 (Vanilla JS)\*\*：无框架纯原生交互逻辑（包括开场封面过渡、弹窗管理、剪贴板一键复制、表单校验等）。
